# TheatreObjects

This program allows users to manage, gather, and organize objects needed for theatrical productions.


## Why This Project?

It is difficult to collect and check off needed materials, costumes, and props for a theatrical production. Often multiple lists are created and not everything is on every list, which may cause problems during the actual shows.

## How it Works

Users can input what objects they need for a production, such as a prop or costume, as well as any requirements, and the program will put it into a list that the user can view later. The user can check items that have been gathered or made off the list. The list and objects are serialized to a text file to be imported again at a later time, allowing the user to take the list with them to different machines.


## Tech Stack 
- **Language:** Java 
- **Libraries:** Java's serialization library and IO library
- **External tools:** Possibly Google App Scripts
